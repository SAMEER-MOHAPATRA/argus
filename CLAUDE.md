## Agent skills

### Issue tracker

Issues live in this repo's GitHub Issues (`gh` CLI). External PRs are not a triage surface (solo repo). See `docs/agents/issue-tracker.md`.

### Triage labels

Default names: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context — one `CONTEXT.md` + `docs/adr/` at the repo root. See `docs/agents/domain.md`.
